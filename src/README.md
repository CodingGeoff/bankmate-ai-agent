# 银伴 AI | BankMate

银伴 AI 是面向个人日常金融服务的 AI Banking Agent 竞赛原型。作品以自然语言为统一入口，围绕模拟转账、账单分析、订阅管理和跨场景任务，构建“理解需求—业务校验—用户确认—执行回执”的可追溯闭环。

**运行边界：**作品使用虚构账户及模拟业务接口，不连接真实银行，不产生真实资金交易。默认规则解析；可选接入支持 OpenAI Chat Completions 工具调用的大模型。演示验证码、风控和锁定机制均为本地模拟；不可用于真实客户数据、生产服务或不可信网络。

## 快速启动

需要 Python 3.9 或更高版本，不需要安装额外依赖。

```bash
cd src
python3 app.py
```

浏览器访问 `http://localhost:8000`；Windows 可使用 `python app.py`。可用 `PORT=8080 python3 app.py` 指定端口。服务默认绑定所有网卡，**仅在可信演示环境中运行**。点击侧栏“重置演示数据”可恢复初始状态。`bankmate.db` 在首次启动时创建。

## 场景与体验

| 场景 | 输入示例 | 体验重点 |
| --- | --- | --- |
| 模拟转账 | 给林晓转200元，还饭钱 | 同名选择、账户尾号核对、确认及回执 |

| 订阅管理 | 看看我有哪些订阅和自动续费；取消视频会员 | 区分疑似扣费和模拟协议，取消前确认 |
| AA 平摊 | 100元，3人AA平摊 | 整数分均分及余数处理，生成模拟计划 |
| 定时转账 | 2027年12月20日定时给王晨转200元 | 保存未来计划，不自动扣款 |
| 卡片管理 | 挂失我的银行卡 | 演示红色操作与卡片状态 |

## 模型工具调用

默认无需模型密钥，使用规则模式。启用工具调用需要具备工具调用能力的 OpenAI 兼容模型。代码支持显式配置多个供应商，按顺序尝试；只有被明确配置的供应商会收到请求。`.env.example` 为配置示例，**应用不自动读取该文件**，请在启动服务前设置环境变量。

例如，配置 OVHcloud 匿名测试接口：

```bash
export BANKMATE_TOOL_AGENT=1
export BANKMATE_PROVIDERS=ovh
export BANKMATE_ALLOW_ANONYMOUS=1
export OVH_MODEL=gpt-oss-20b
python3 app.py
```

匿名接口可能限流、不可用或调整政策；输入会发送给第三方。也可按 `.env.example` 配置硅基流动、DeepSeek、Groq、Gemini、OpenRouter 或 OpenAI 的模型和 API Key。模型能力、账号权限、服务条款和费用以供应商为准。密钥仅放在本地环境变量，不要提交仓库或放入前端。

工具调用包含上月账单、订阅、收款人查询和转账草稿；服务端校验关键字段。模型不能确认或执行转账。调用失败后可回退至规则解析。OVHcloud 已进行一次真实只读工具往返；其他供应商尚待凭据与联网验证。

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

测试运行于临时 SQLite 数据库，覆盖模拟业务、确认凭证、转账幂等、风险分级、工作流一致性、模型工具校验和备援路由。工具调用与金融沙箱的单元测试使用模拟响应。更多结果与范围见 `../evidence/test-report.md`。

## 安全与实现范围

- 高风险模拟操作需确认；转账日累计超过 1000 元和卡片挂失要求演示验证码 `246810`。固定验证码仅用于展示，**不是真实多因子认证**。
- 工作流创建及模拟预留更新使用 SQLite 事务；重复确认不会重复预留。本标签页刷新可恢复待确认工作流，关闭标签页后不保证恢复。
- 当前为单用户演示，未实现真实身份认证、用户隔离、CSRF 防护或生产级密钥管理；代码不用于真实银行业务。
- 模型服务、第三方金融沙箱及模拟银行之间的功能范围不同。Plaid 沙箱探针独立运行，未与主账本同步；定时计划、消息提醒不执行真实外部动作。
- 完整安全边界、测试方法与已知风险见配套材料。

## 六场景扩展演示

- 年度账单：输入“年度账单”；根据当年模拟流水分类汇总。
- 理财：输入“对比理财产品”“申购稳健示例100元”“查看理财持仓”“赎回稳健示例50元”。申购/赎回需要确认和演示码。产品、持仓、风险均为虚构，不提供真实适当性评估。
- 卡片：输入“申请银行卡”“银行卡限额调整为2000元”“挂失我的银行卡”“解锁银行卡”。只改变模拟数据；限额影响模拟转账，不影响真实银行卡。
- 订阅：输入“自动识别订阅”，从本地订阅类别流水按不同月份重复商户提示线索；不证明真实签约，不实际推送。
- 生日：固定任务确认后预留模拟预算、创建提醒并记录鲜花蛋糕计划；不实际订购、支付或推送。

以上为六个方向的代表性模拟链路，不代表六个方向所有细项已实现：手机号转账、真实到期转账、真实AA收款、真实风险测评、真实推送与商家订购均未接入。
